Pour le parsing du PDF, nous avions plusieurs choix de :
- Parser
- Format d'output

Pour le parser, après avoir testé plusieurs (comme Partition) dont certains avaient besoin d'un GPU pour l'OCR, nous avons utilisé la library python proposé par l'enseignant Docling. Cette library permet aussi simplement d'export le pdf au format qu'on voulait du Markdown.
Le markdown est très utile après pour une séparation par partie, bien que le format txt marchait aussi.
